What’s in the design
--------------------

Palette: cream #f2efe8, ink #161512, rust #8b2e1b, muted grays/taupe (no blue/purple “stock space”).

• Dark charcoal to warm cream horizontal gradient (horizon / deep sky).
• Rust “nebula” glow and a small planet/moon with orbital arcs (subtle MAR / sync metaphor).
• Star field in cream and taupe (tiny dots, not neon).
• Right side: headline “Precision AI.” / “Zero compromise.” (condensed caps; rust on “AI.” and “compromise.”), subtle rust-line grid, scattered pixel squares in brand colors, vertical rust divider before the text block.
• Wordmark bottom-left: MAR in cream, SYNC in rust, tag lines above, rust rule under the block.


Note
----

Do not squash this wide art to 1128 x 191; it will crush the composition. Upload cover-space-2400x1200.png and use LinkedIn’s editor to frame it (or use cover-space-1536x768.png if you prefer the max-size preset).
